# 变更日志

本文档记录了KY-Admin项目的所有重要变更。

## [1.0.0] - 2025-04-30

### 添加

- 用户认证与授权系统
  - JWT认证机制
  - RBAC权限控制
  - 基于Casbin的权限管理
  - 多租户支持
- 系统管理功能
  - 用户管理CRUD
  - 角色与权限管理
  - 菜单管理
  - 部门管理
  - 字典管理
- API框架
  - RESTful API设计
  - 统一响应格式
  - API版本控制
  - 请求参数验证
  - 跨域支持
- 测试框架
  - 单元测试
  - 集成测试
  - 性能测试
  - 测试覆盖率监控
- 文档集成
  - Swagger文档
  - YAPI接口管理
- 容器化与CI/CD
  - Docker容器化
  - GitHub Actions自动化流程
  - 多环境配置

### 变更

- 无（首次发布）

### 修复

- 无（首次发布）
